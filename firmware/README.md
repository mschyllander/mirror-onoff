# Firmware

Projektets befintliga programvara har ännu inte bifogats. Lägg den här tillsammans med uppgifter om byggmiljö, bibliotek, kortvariant och GPIO-koppling.

Dokumentera också hur strömmen filtreras, hur ON/OFF bestäms och vad styrningen gör när tillståndet ändras. Ange eventuella nätverksintegrationer först när de är bekräftade.

Använd exempelkonfiguration utan personliga lösenord om programmet kräver nätverksuppgifter.
